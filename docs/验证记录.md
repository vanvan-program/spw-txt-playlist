# 1.0.0 验证记录

验证日期：2026-10-22。适配对象：本机 Steam 版 SPW 1.19.0，Workshop API 0.1.0-dev22。

开源发布前再次使用 `--offline --rerun-tasks` 执行 `test plugin hostIntegration`：7 个单元测试、9 项隔离集成检查和安装包打包均通过。安装包附带项目 MIT 许可证。编译器报告的弃用提示涉及既有异常处理及测试辅助接口，不影响本次构建结果。

## 已完成

- JDK 25、Kotlin 2.4.20、Gradle 9.8.0 离线构建及官方 `plugin` 任务打包成功。
- 7 个单元测试通过：中文、日文、空格、特殊符号路径；原始行号；重复路径；UTF-8 / UTF-16 BOM / GB18030；曲库路径歧义；收录失败；全部无效不建歌单；权限拒绝；预览后文件删除。
- 在真实 SPW 类、Room 和 SQLite 上通过 9 项隔离集成检查：按指定顺序新建、去重追加、重复导入幂等、保留歌名倒序的现有显示顺序、部分写入后的整体回滚、权限拒绝与插件停用、拒绝未适配版本、调用真实 RepoService 收录新音频、关闭重开数据库后保留顺序。
- Swing 窗口检查通过：读取预览、切换追加、显示逐行结果、失败导出入口、关闭窗口、导入中停用并取消未提交任务。
- 使用本地 TXT 清单进行了插件解析器的只读预览。这里没有对正式曲库执行匹配或导入；个人清单及其内容不随项目发布。
- 安装包清单、入口、中文元数据、权限、配置按钮和关键类指纹检查通过；不包含宿主 API、Kotlin / Compose 运行库、测试辅助类、Loved.txt 或歌曲文件。

## 隔离方式与验证边界

所有写入测试位于 `build/host-test/`，使用独立 JVM、新建 Room 数据库、测试音频、独立 APPDATA / LOCALAPPDATA / 临时目录和内存 Preferences。测试进程中将数据库单例指向测试库，测试辅助类不进入安装包。没有向正式歌单导入歌曲。

窗口图使用模拟曲库数据，由插件自己的 Swing 组件实际绘制，不是 SPW 安装验证截图。数据库重开验证了持久化顺序，但没有替代正式播放器的重启与界面验收。

尚待用户在正式 SPW 中完成：从创意工坊本地导入安装包、授予权限、打开配置入口、试导入一个测试歌单，并在播放器重启后查看。宿主内部接口受关键类指纹限制，其他版本或同版本不同构建需要重新适配。

## 复验命令

```powershell
.\scripts\build.ps1 -Offline
.\gradlew.bat uiVerification --offline
.\gradlew.bat hostIntegration '-PspwHome=C:\app\steam\steamapps\common\Salt Player for Windows' --offline
.\gradlew.bat previewTxt '-PtxtFile=C:\Music\playlist.txt' --offline
```

Gradle 缓存使用项目目录内 `.tools/gradle-home`；手动运行命令时需先设置 `JAVA_HOME` 与 `GRADLE_USER_HOME`，参见构建脚本。
